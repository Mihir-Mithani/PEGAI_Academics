# AI Career Counsellor

A single-file, persona-based AI Career Counsellor built with HTML, CSS, JavaScript and the Gemini API.

## Problem statement

Students often receive generic career advice. This application lets a student ask one career question and receive meaningfully different recommendations from specialized counsellor personas.

## Objective

Demonstrate persona prompt engineering with:

**Role → Audience → Context → Format → Constraints → Language → User Question → Gemini API → Persona-specific responses**

For multiple personas, the application sends the selected persona instructions together with the same question in **one Gemini `generateContent` request**.

## Gemini API integration

The app calls:

`https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash:generateContent`

The API key is supplied at runtime in the UI. It is not hard-coded into `index.html`, so no secret is committed to the repository.

The app uses a structured JSON response so each persona can be rendered separately and, when multiple personas are selected, a comparison table can be shown.

## How to run

1. Download/clone the project.
2. Open `index.html` in a modern browser.
3. Select one or more personas.
4. Enter a career-related question.
5. Paste a Gemini API key into the runtime API-key field.
6. Click **Get Career Advice**.

If your browser blocks direct API requests when opening a local file, serve the folder with a simple static server, for example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Security note

Do **not** put your real Gemini API key in the source code, `.env` files committed to GitHub, README, screenshots, or public repository.

For a production deployment, use a backend/serverless proxy so the API key never reaches the browser. This assignment's one-file constraint is why this implementation requests the key at runtime instead of publishing it.
