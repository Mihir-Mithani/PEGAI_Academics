## 🚀 Quick Start

### Prerequisites
- Python 3.10+
- Jupyter Notebook / JupyterLab
- Required Python packages (install via `pip install -r requirements.txt` if available)

### Running Notebooks
```bash
# Navigate to the repository
cd PEGAI

# Start Jupyter Lab
jupyter lab

# Open Experiment1.ipynb or Experiment2_PEGAI_Data_Cleaning_Prompts.ipynb
```

### Running Game Scripts
```bash
cd Assignments/exp1/Games
python game1.py
python game2.py
```

## 📌 Important Notes

1. **Virtual Environments**: The repository contains `venv/` and `venv313/` directories for Python virtual environments. These are excluded from git tracking via `.gitignore`.

2. **File Formats**: 
   - `.ipynb` files are Jupyter Notebooks - best viewed in Jupyter Lab/Notebook
   - `.pptx` files are PowerPoint presentations
   - `.pdf` files are portable document formats
   - `.docx` files are Microsoft Word documents

3. **Large Files**: Some study material files (PPTX/PDF) are large (30MB-100MB) due to embedded images and content.

4. **Academic Integrity**: This repository is for educational purposes. Please adhere to your institution's academic integrity policies when using or contributing to this material.
